# WhatsApp Cold Outreach — Solo Delhi Real Estate Agents

## Target
Solo real estate agents in Delhi NCR found via:
- 99acres.com agent listings
- MagicBricks.com agent profiles
- JustDial real estate agents
- Housing.com agent directory
- Local Dwarka/Gurgaon/Noida Facebook groups

## Message (Hinglish)

```
Namaste {agent_name} ji,

Main ek AI tool bana raha hoon jo real estate agents ke liye kaam karta hai — jaise ek virtual receptionist.

Yeh kya karta hai:
✅ Aapke number pe aane wali calls automatically attend karta hai — Hindi aur English dono mein
✅ Caller se property details poochta hai (budget, area, BHK type)
✅ Aapko turant email + SMS bhejta hai caller ki poori details ke saath
✅ Website pe bhi chat widget lagta hai — visitor se baat karta hai

Matlab — aap meeting mein ho, driving kar rahe ho, ya kisi aur client ke saath ho — tab bhi koi lead miss nahi hogi.

Cost: Sirf ₹5,000/month. Pehle 7 din free trial.

Kya aap 5 minute ka demo dekhna chahenge? Main call pe dikhata hoon — aap khud apne number pe call karke test kar sakte hain.

Dhanyavaad 🙏
{your_name}
PropBot AI
```

## Follow-up Message (if no reply in 2 days)

```
{agent_name} ji, bas ek follow-up.

Humne Delhi ke kuch agents ke saath trial kiya — unka feedback hai ki monthly 15-20 extra leads capture ho rahe hain jo pehle miss ho jaate the.

Agar interest ho toh ek quick 5-min demo set kar lete hain. No commitment.

Free trial ke liye reply karein 👍
```

## Tips
- Send between 10 AM - 1 PM or 4 PM - 7 PM (agent's free time)
- Personalize: mention their area ("Dwarka mein aapke listings dekhe")
- Don't send to more than 10/day to avoid WhatsApp spam flags
- If they reply with interest, offer to set up a call within 24 hours
- Demo script: call their current number, show Priya answering, show the email alert
